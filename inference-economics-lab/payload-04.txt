            <summary>How the simulator works</summary>
            <p>Each turn prices the active context and generated output. Cache hits use the cache-read rate; missed reusable prefixes use the cache-write rate; new user tokens use the standard input rate. Compaction is modelled as an extra read-and-generate pass that replaces dynamic history with a smaller state. Retrieval keeps a fixed working set rather than replaying the complete transcript. Delivery multipliers are applied uniformly in this teaching model, although real providers may discount input, cache, and output differently. Provider implementations differ, so the pricing editor is intentionally exposed.</p>
